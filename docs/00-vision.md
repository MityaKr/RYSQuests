# 00 · Что строим

RYSQuests это квест-мод для сборок Minecraft 1.21.1 (NeoForge), замена FTB Quests. Он решает шесть проблем, которые видны на книге из 2000+ квестов:

1. Редактор только в игре и SNBT с числовыми id. У нас книга это JSON-файлы со строковыми id, один файл на квест. Генераторы и git работают из коробки, редактор в игре пишет те же файлы (редактор не в MVP).
2. Паутина зависимостей с ручной раскладкой. У нас автораскладка слоёного графа с кэшем и ручной фиксацией узлов.
3. Тормоза на больших главах. У нас виртуальный рендер карты, свёрнутые выполненные ветки, прогресс диффами.
4. Хрупкий прогресс при переименовании. У нас `migrations.json` с rename/merge/remove и dry-run.
5. Квест и рецепт живут отдельно. У нас рецепт в карточке квеста через мост к вьюеру рецептов (JEI/EMI сейчас, RYScope позже).
6. Автор слеп. У нас отчёты валидации (циклы, битые предметы, переводы) и позже локальная аналитика воронки.

Фирменные элементы игрока: домашний экран «Что дальше», вид «Поток» (вертикальная лента главы, квест раскрывается на месте), HUD-стикеры закреплённых квестов, темы Slate и Vanilla через библиотеку RYScore.

Что НЕ входит в первую реализацию (решено автором): концепт «Компаньон» (панель на краю экрана, фразы-действия, диагностика «что мешает», Ctrl+K). Фундамент должен позволить добавить его позже, но проектировать под него специально не нужно.

## Пользователи

- Игрок сборки: открывает книгу по клавише, видит текущий квест, сдаёт, получает награду, идёт дальше. Хочет, чтобы книга не тормозила и не терялся прогресс.
- Автор сборки (в первую очередь сам автор мода, с Python-генератором): пишет JSON, перезагружает `/reload`, видит ошибки, переносит книгу из FTB Quests вместе с прогрессом игроков.

## Мерило успеха MVP

Книга RepYS (около 2300 квестов, 27 глав) импортирована из FTB Quests вместе с прогрессом тестового сервера, открывается менее чем за 200 мс после первого входа, переключение глав без заметной паузы, игрок проходит квест от начала до награды без обращения к документации.
