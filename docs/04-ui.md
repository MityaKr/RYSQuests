# 04 · Интерфейс

Референс визуала: `design/Main.dc.html` (карта + карточка), `design/Comfort.dc.html` («Поток»), `design/Home.dc.html` («Что дальше»), `design/Hud.dc.html` (стикеры), `design/List.dc.html`, `design/Timeline.dc.html`, `design/Dev.dc.html`. Макеты 1280×800 это окно книги 1200×728 в экране; в игре книга занимает 90 % экрана при GUI Scale авто, минимум 854×480.

## Общая структура экрана книги

```
┌ шапка: логотип · табы видов · поиск · команда · закрыть ─────────────────────┐
│ ┌ главы (232) ┐ ┌ область вида ───────────────────────┐ ┌ карточка (392) ┐ │
│ │ список с    │ │ Поток / Карта / Список / Что дальше │ │ квест:         │ │
│ │ прогрессом  │ │                                     │ │ задачи, награды│ │
│ │             │ │                                     │ │ текст, рецепт  │ │
│ └─────────────┘ └─────────────────────────────────────┘ └────────────────┘ │
└ подвал: подсказки клавиш · состав ───────────────────────────────────────────┘
```

При ширине меньше 1100 px карточка квеста становится оверлеем поверх области вида, список глав сворачивается до иконок (как рейка в `Comfort.dc.html`).

## Виды (MVP: Поток и Карта; затем Что дальше, Список)

**Поток** (по умолчанию для глав без сильного ветвления): вертикальная лента. Сверху свёрнутая строка «Выполнено N из M», затем доступные и активные квесты по порядку топологической сортировки, текущий раскрыт на месте (задачи, кнопка «Сдать», награда), ветвления как блок «Дальше, на выбор» из 2–3 карточек, остаток за ссылкой «ещё N впереди». Клавиши: ↑↓ перемещение, Enter раскрыть, G сдать.

**Карта**: граф главы на точечной сетке 24 px, автораскладка (см. ниже), группы-подглавы пунктирной рамкой с заголовком, выполненные ветки свёрнуты в один узел «✓ свёрнуто N», мини-карта в углу, Shift+колесо масштаб, перетаскивание ЛКМ по фону, F фокус на пути к выбранному квесту. Рендер только видимых узлов и рёбер.

**Что дальше** (M8): три рекомендации (доступен, ближе к завершению, ведёт к следующей главе), награды к получению, прогресс глав, лента эпох.

**Список** (M8): группы по статусу, строка с действием.

## Карточка квеста

Заголовок с иконкой, подзаголовок «глава · требует · открывает», кнопка закрепить. Табы: Задачи (по умолчанию), Текст, Награды сгруппированы под задачами. Строка задачи: чекбокс состояния, иконка, текст, прогресс `n / m`, кнопка «Сдать» для consume. Награды: слоты, «выберите 1 из N» с акцентной рамкой на выбранной. Текст с разметкой; рецепт нужного предмета через `RecipeViewerBridge`, если доступен. Низ: «Зависимости», «Ссылка в чат» (вставляет `[[quest:id]]` в чат как компонент с кликом).

## HUD-стикеры

Закреплённый квест это стикер на `ryscore.hud.StickerBoard`: заголовок, задачи с чекбоксами, прогресс-полоса 4 px, ширина до 300 px. Доска справа сверху по умолчанию, перетаскивается, позиция в клиентском конфиге. Прячется, когда открыт любой экран, и в бою (конфиг). При выполнении задачи стикер коротко подсвечивается, при завершении квеста исчезает с тостом «Квест выполнен · награда ждёт в книге · K».

## Клавиши

| Клавиша | Действие |
|---|---|
| K | открыть книгу на текущем квесте / закрыть |
| G | сдать всё готовое по закреплённым и текущему (с тостом-сводкой) |
| A | закрепить/снять выбранный квест (в книге) |
| Esc | закрыть |
| Ctrl+F | поиск в книге |

Все переназначаемые через стандартные `KeyMapping`.

## Темы (RYScore)

Тема это `assets/<ns>/ryscore/themes/<id>.json` плюс текстуры в `assets/<ns>/textures/gui/<theme>/`. Загружается ресурспаком, переключается в настройках без перезапуска. В MVP две: `ryscore:slate` (по умолчанию) и `ryscore:vanilla`.

Черновик формата (из концепта RYScope, уточнить при реализации):

```json
{
  "id": "ryscore:slate",
  "name": "Slate",
  "colors": {
    "panel.bg": "#1c1f27", "panel.border": "#2c313d", "sidebar.bg": "#16181f",
    "card.bg": "#20242e", "card.border": "#343a48",
    "slot.bg": "#12141a", "slot.border": "#262a35",
    "text.primary": "#f7f8fb", "text.body": "#e6e8ee", "text.muted": "#8b93a5", "text.dim": "#5f6678",
    "accent": "#e4b23c", "accent.text": "#15181f",
    "state.ok": "#6fcf8f", "state.warn": "#e4b23c", "state.bad": "#e36b6b", "state.info": "#8fb4ff",
    "overlay": "#0e1016", "overlay.alpha": 0.55
  },
  "metrics": { "panel.radius": 12, "card.radius": 14, "slot.radius": 6, "button.radius": 9, "bevel": 0, "slot.size": 18, "slot.gap": 3 },
  "textures": { "slot": "ryscore:textures/gui/slate/slot.png", "panel": "ryscore:textures/gui/slate/panel.png" },
  "effects": { "shadow": true, "animations": "normal" }
}
```

Скругления и тени в Minecraft рисуются nine-slice текстурами (`GuiGraphics.blitSprite` со `sprite` из `gui/sprites`), не CSS. Токены цветов применяются к тексту, заливкам и тонировке текстур.

Квест-специфичные токены (из `02-design.md` концепта): узел выполнен border `#2f6b3f`, текст `#6fcf8f`; активный узел border accent 2 px; закрытый opacity 0.6 с замком; рёбра `#3d7a4d` / accent / `#3a3f4d`; фон карты `#15171e` с точками `#262a35`.

## Виджеты RYScore (MVP)

`Panel`, `Slot` (предмет, количество, шанс, подсветка состояния), `ProgressBar`, `Button` (с клавишной подписью), `Tabs`, `ScrollList` (виртуализованный: создаёт виджеты только для видимых строк), `Tooltip`, `TextBlock` (разметка). Все виджеты берут цвета и метрики из активной темы, а не из констант.

## Автораскладка (клиент, `layout`)

1. Узлы главы минус свёрнутые выполненные ветки.
2. Слои: длиннейший путь от корней (квесты без зависимостей внутри главы). Фиксированные узлы (`layout.x/y`) закрепляются за слоем по x.
3. Порядок в слое: барицентр соседей, 4 прохода вниз-вверх, стабильная сортировка.
4. Координаты: слой → колонка (ширина узла 132–200 px + 48 px), позиция в слое → строка (высота 40–56 px + 24 px), выравнивание по сетке 24.
5. Рёбра ортогональные: горизонталь → вертикаль → горизонталь, с общим вертикальным сегментом на полпути между слоями.
6. Результат кэшируется по `(bookHash, chapterId, collapsedSetHash)` в `config/rysquests/layout-cache/`.

Считается в фоне, во время расчёта показывается предыдущая раскладка или спиннер.

## Доступность

Все действия доступны с клавиатуры; фокус виден (рамка accent). Состояние узла дублируется текстом и формой, не только цветом. Минимальные цели клика 20 px в GUI-пикселях (в масштабе 2 это 40 px экрана).
