# Промпт для ИИ, который ведёт сборку

Скопируй текст ниже в сессию ИИ сборки. `<RYSQuests>` это папка с исходниками мода (клон https://github.com/MityaKr/RYSQuests). Значения в угловых скобках замени или дай ИИ выяснить самому.

---

Ты ведёшь код сборки Minecraft 1.21.1 NeoForge. В сборку входит книга квестов RYSQuests. Настрой её.

**Что прочитать сначала, в этом порядке**

1. `<RYSQuests>\docs\GUIDE.md`. Полный гайд: все функции и рабочие примеры. Главный документ, его достаточно для большинства задач. Все примеры JSON в нём проверены автотестом мода, копируй их структуру.
2. `<RYSQuests>\docs\for-pack-authors.md`. Как перестроить книгу после импорта из FTB Quests: что где показывается и как заполнять.
3. `<RYSQuests>\docs\02-data-format.md`. Справочник полей, если в гайде чего-то не хватило.
4. `<RYSQuests>\examples\example_pack\`. Живой пример книги: главы, гайды, все три шаблона вкладок, магазин, достижения.
5. `<RYSQuests>\examples\kubejs\server_scripts\rysquests_coin_exchange.js`. Готовый блок обмена старых монет.

Репозиторий мода только читай. Правки делай в файлах сборки.

**Куда писать**

Книга лежит в датапаке сборки по пути `data/<ns>/rysquests/`, тексты в `assets/<ns>/lang/`. Если датапак сборки создаётся генератором, меняй генератор, а не его результат. Пространство имён: `<ns>`, предположительно `repys`, проверь по существующим файлам. Скрипты KubeJS кладутся в `kubejs/server_scripts/`.

**Что нужно сделать**

1. Вкладки: в `book.json` поле `sections`. Вкладка видна игроку, только если записана здесь и в ней есть содержимое. Порядок: `story`, `guides`, атлас сборки, атлас добычи, `shop`, `achievements`.
2. Атлас сборки: файл `sections/build_atlas.json`, шаблон `matrix`, `compact: true`. Строки это направления (Техника, Энергия, Хранение, Магия, Природа, Финал), столбцы это эпохи сборки, способ в ячейке это мод. Образец в разделе 11 гайда.
3. Атлас добычи: файл `sections/mining_atlas.json`, шаблон `matrix`. Строки это ресурсы, столбцы это стадии (ранняя, средняя, поздняя), способы это реальные способы добычи в этой сборке. Образец там же.
4. Магазин: файлы `shop/<id>.json`, раздел 12. Перед выпуском выполни `/rysquests dev report` и убедись, что отчёт `shop_cycles` (сделки, печатающие деньги) пуст.
5. Достижения: файлы `achievements/<id>.json`, раздел 13.
6. Монеты: блок обмена старых физических монет на квестовые. Возьми пример из пункта 5 списка чтения, положи в `kubejs/server_scripts/`, задай блок, валюту и таблицу курсов.

7. Многоблочные машины: `/rysquests import patchouli machines <ns>` переносит книгу `patchouli_books/machines` в гайды с 3D-структурами, раздел 10 гайда. На страницы можно добавить настоящие рецепты `[[recipe:id#категория]]` и размышления `[[ponder:id]]`.

**Что выяснить самому и не выдумывать**

- Id предметов, существ, достижений и тегов бери из `logs/rysquests-registry.json`. Файл создаёт команда `/rysquests dev registry`. Id старых монет ищи там же или в файлах мода, откуда они взяты.
- Стадия в полях `stage` и `stage_required` это id достижения игры, либо стадия провайдера. Если стадию ничего не выдаёт, квест или столбец навсегда останутся закрытыми, отчёт покажет это как `unreachable`.
- Курс монет и цены это баланс сборки. Если автор их не задал, спроси, а не назначай сам.

**Правила**

- Id квестов, страниц, сделок и достижений строковые и постоянные. Переименование только через запись `rename` в `migrations.json`, иначе игроки потеряют прогресс.
- Вместо удаления файлов переноси их в `_stale`.
- Не меняй инстанс разработки сборки напрямую без согласия автора, тестируй на копии.
- Тексты для игроков показывай автору черновиком.

**Как проверить результат**

- Без игры: `python <RYSQuests>\tools\rysquests_check.py <корень пака> --registry logs/rysquests-registry.json --lang ru_ru`. Проверяет главы и квесты.
- В игре: `/reload`, затем `/rysquests validate` и `/rysquests dev report`. Эти команды проверяют и вкладки, сделки, достижения. Отчёт лежит в `logs/rysquests-report.json`.
- Обменник проверь в игре: правый клик по блоку с монетой в руке, баланс виден в разделе «Магазин» или командой `/rysquests wallet get <игрок> coin`.

## Пометки для автора

- `<ns>` оставлен неподставленным: мод не знает пространство имён сборки. Для RepYS это, судя по примерам в документах, `repys`, но ИИ должен сверить это с файлами.
- Замени `<RYSQuests>` на путь к исходникам мода у себя.
- Пункт про `_stale` и копию инстанса это пример правил. Если для сборки правила другие, поправь его.
